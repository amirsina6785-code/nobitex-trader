# Nobitex Phone Trader — نسخه کامل موبایلی

این بسته برای استفاده از **گوشی بدون لپ‌تاپ/کامپیوتر** طراحی شده است.
رابط کاربری یک وب‌اپ موبایلی است و سرور روی VPS اجرا می‌شود.

## امکانات
- داشبورد موبایل
- قیمت زنده BTCIRT از نوبیتکس
- وضعیت ربات
- Paper Trading
- START / STOP / Emergency Stop
- موجودی و Equity
- سود/زیان و Drawdown
- تنظیم سرمایه، ریسک هر معامله و سقف ضرر روزانه
- ثبت معاملات
- بدون مجوز برداشت
- کلیدهای حساس فقط روی سرور
- ذخیره وضعیت روی فایل JSON
- آماده Docker

## راه‌اندازی روی VPS
1. `.env.example` را به `.env` کپی کنید.
2. `CONTROL_API_KEY` را با یک مقدار تصادفی طولانی پر کنید.
3. `docker compose up -d --build`
4. آدرس HTTPS سرور را با Chrome گوشی باز کنید.
5. از Chrome گزینه Add to Home screen را بزنید.

## هشدار
این نسخه برای ایمنی، **معامله واقعی را فعال نمی‌کند**. ابتدا Paper Trading، سپس تست‌نت و بک‌تست با داده واقعی لازم است.
هرگز API key نوبیتکس را داخل چت ارسال نکنید.
